# 제품 구현 현황 (2026-11-04)

## 실제 동작하는 페이지
| 주소 | 내용 | 데이터 |
|---|---|---|
| `/` | 메인: 서비스 소개, 카테고리, 곧 열리는 모임 6개, 참여 방법, 호스트 소개, 호스트 모집 안내 | DB |
| `/meetups`, `/meetups?category=…` | 모임 목록·카테고리 필터 (가까운 일정 순, 남은 자리·마감 표시) | DB |
| `/meetups/[id]` | 모임 상세: 일정별 남은 자리, 소개, 진행 순서, 참여 안내, 환불 안내, 호스트, 모바일 하단 신청 바 | DB |
| `/hosts/[id]` | 호스트 프로필과 진행 중인 모임 | DB |
| `/signup`, `/login`, `/forgot-password`, `/reset-password` | 이메일 가입·인증·로그인·재설정 | DB |
| `/me` | 프로필·연락처 수정 | DB |
| `/admin`, `/admin/members`, `/admin/audit`, `/admin/mfa` | 관리자: 2단계 인증, 회원·역할 관리, 감사 기록 | DB |
| `/host` | 호스트 전용 자리 (기능 없음) | — |

- 샘플 데이터: `supabase/seed.sql` (로컬·CI 전용, `is_sample = true`, 화면에 "샘플" 표시)
- 신청 버튼은 "곧 오픈"으로 비활성 (신청 기능 미구현)

## 아직 없는 핵심 기능 (우선순위 순)
1. 호스트 신청·승인, 호스트의 모임 등록·수정 (`/host`)
2. 참가 신청·정원 관리 (중복·초과 방지), 참가자 신청 내역 (`/me/bookings`)
3. 관리자 모임 승인·운영 화면
4. 모임 사진 업로드 (현재는 카테고리별 디자인 표지)
5. 결제(테스트 모드), 취소·환불, 후기, 저장·팔로우

## 알려진 제한
- `/meetups/[id]`, `/hosts/[id]`에서 없는 주소는 "찾을 수 없음" 화면과 검색 비노출 표시가 나오지만 HTTP 상태는 200 (Next.js 화면 틀 선전송 구조)
