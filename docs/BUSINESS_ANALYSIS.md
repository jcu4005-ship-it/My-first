# Gathering(가칭) 사업 방향과 사업 분석 (2026-11-06 기준)

> 타 플랫폼 비교용 정리. **숫자 중 "가설" 표시는 확정 정책이 아니라 검증할 값**이다.
> 경쟁사 정보는 공개 자료로 확인한 범위만 적었고, 확인하지 못한 것은 "확인 필요"로 표시했다.

## 1. 한 줄 정의 (현재)
**검증된 전문가·크리에이터가 4~10명 소수 정예로 직접 가르치는 오프라인 클래스 마켓플레이스.**
겉모습은 세련된 어반 라이프스타일 브랜드, 핵심 가치는 "배우고 결과물을 가져가는 경험".

- 브랜드 카피: "Make time for what inspires you." / "취향이 맞는 사람들, 새로운 경험이 시작되는 곳."
- 서비스명: Gathering (가칭, 미확정)

## 2. 방향이 바뀌어 온 과정
| 시기 | 방향 | 바꾼 이유 |
|---|---|---|
| 설계 v1.0 | 호스트가 여는 **오프라인 모임** 플랫폼 (독서·러닝·와인·네트워킹 등 친목 포함) | 처음 아이디어 |
| 11/3 | **전문가 소수 정예 클래스**로 전환. 친목형 카테고리 비활성, 호스트 경력 심사 필수, "수업 후 할 수 있는 것" 필수 | 친목 모임은 문토·소모임·동행클럽이 이미 강함, 돈을 낼 이유가 약함 |
| 11/4 | 인플루언서·크리에이터를 강사로 영입하는 모델 추가 (런칭 대행, Originals, 프라이빗 클래스, 콜라보) | 공급(강사) 확보 + 크리에이터 팬덤을 통한 모집 |
| 11/4 | 디자인을 **Premium Urban Lifestyle Club**으로 전면 리뉴얼, 전시장형 갤러리, 휴대폰 중심 | 흔한 예약 사이트처럼 보이지 않기, 사용자 90% 이상 휴대폰 |
| 11/5 | **호스트 육성 + 유료 클래스 기획 서비스** 모델 | 참가자를 호스트로 키워 공급 문제를 해결, 수수료 외 수익원 |

**정리:** "누가 무엇을 파는가"는 **실력(배움)**으로 정해졌고, "어떻게 보이는가"는 **라이프스타일 브랜드**로 정해졌다. 이 둘의 균형이 앞으로의 핵심 과제다 (8장 리스크 1번).

## 3. 고객과 가치 제안
### 3-1. 참가자 (수요)
- 대상: 퇴근 후·주말에 2~3시간 배워서 결과물이나 실력을 얻고 싶은 직장인·성인, 휴대폰으로 찾고 결제하는 사람
- 얻는 것: ① 검증된 사람에게 배운다 ② 적은 인원이라 한 명씩 봐 준다 ③ 무엇을 배우는지 신청 전에 안다(난이도, 수업 후 할 수 있는 것) ④ 감각적인 공간과 비슷한 관심사의 사람들

### 3-2. 호스트 (공급)
| 유형 | 누구 | 얻는 것 |
|---|---|---|
| Expert | 경력 심사를 통과한 현업 전문가 | 모집·결제·운영 대행, 추가 수입 |
| Creator | 인스타그램 등 콘텐츠 크리에이터 | 광고 외 새 수익원, 팬과의 오프라인 접점, 기획·운영 지원 |
| Community Host (기획) | 클래스를 들으며 성장한 일반 참가자 | 낮은 진입 비용으로 첫 클래스 개설 |

### 3-3. 운영팀 (플랫폼)
호스트 심사, 클래스 검수·공개, 결제·환불, 정산(초기 수동), 품질 관리

## 4. 수익 구조
| 수익원 | 내용 | 시기 | 상태 |
|---|---|---|---|
| ① 거래 수수료 | 클래스 결제액에서 수수료 | 출시부터 | 설계만, 실결제 잠금 |
| ② 크리에이터 수수료 차등 | 섭외·운영 지원 25~30%, 자체 팬덤 모집 15~20% | 크리에이터 영입 후 | 가설 |
| ③ 호스트 기획 패키지 | 강점 분석→콘셉트→커리큘럼→가격·정원→상세 페이지→홍보→출시 | 회원·인지도 확보 후 | 기획 |
| ④ 콘텐츠 제작 | 사진·영상·상세 페이지 제작 | ③과 함께 | 기획 |

- 기본 수수료 등급 (가설, 관리자가 변경 가능): 신규 30% / 성장 25% / 우수 20% / 핵심 파트너 15%
- 수수료는 결제 시점 값으로 저장(스냅샷) → 나중에 등급표를 바꿔도 과거 거래는 그대로
- 카드 수수료(PG)는 초기 플랫폼 부담, 쿠폰은 부담 주체(플랫폼/호스트) 구분 기록
- 정산: 클래스 종료 7일 후 + 분쟁 없음 → 월 2회, **초기에는 관리자가 직접 확인하는 수동 정산** (자동 이체 없음)
- 원칙: **돈을 냈다고 호스트 자격을 주지 않는다** (③과 심사 분리)

### 4-1. 단위 경제 예시 (모두 가정, 계산 예시일 뿐)
| 항목 | 값 |
|---|---|
| 클래스 가격 | 50,000원 |
| 인원 | 8명 |
| 1회 매출 | 400,000원 |
| 수수료 20% | 80,000원 |
| 카드 수수료 (가정 약 3%, 계약 후 확정) | 약 −12,000원 (플랫폼 부담) |
| **플랫폼 1회 순수익 (마케팅·인건비 전)** | **약 68,000원** |

→ 월 100회 열리면 약 680만 원. 클래스 1회당 수익이 작기 때문에 **재수강률과 호스트당 개설 횟수**가 핵심 지표다.

## 5. 경쟁 구도
### 5-1. 시장 지도
```
             사람·관계 중심 ←────────────→ 실력·결과물 중심
 멤버십형 │  필립앤소피, 동행클럽, 트레바리          (빈 자리: 단계형 코스)
 1회 결제 │  문토, 소모임(무료 많음)        프립(액티비티)  탈잉·솜씨당·클래스101(오프라인) ← 우리
```
우리는 "1회 결제 × 실력 중심" 칸에 있다. 이 칸은 원데이 클래스 플랫폼들이 이미 있는 **경쟁이 치열한 칸**이다. 차별화는 "검증·소수 정예·브랜드 감도·크리에이터"에서 나와야 한다.

### 5-2. 비교표
| 항목 | **우리** | 필립앤소피 | 동행클럽(구 넷플연가) | 원데이 클래스 플랫폼 (프립·탈잉·솜씨당 등) |
|---|---|---|---|---|
| 파는 것 | 실력·결과물 | 관계·인연 (초대제 독서 소셜) | 관계·취향 (시즌제 커뮤니티) | 경험·취미 수업 |
| 결제 | 클래스 1회 | 멤버십 (가격 확인 필요) | 3개월 멤버십 약 15만 원 (회사 발표) | 대부분 1회 |
| 인원 | 4~10명 | 확인 필요 | 12~24명 | 클래스마다 다양 |
| 진입 장벽 | 참가자 누구나 / 호스트는 경력 심사 | 추천 또는 1:1 인터뷰 | 프로필 승인 | 대부분 누구나 |
| 진행자 | 검증된 전문가·크리에이터 | 운영진 | 모더레이터 | 등록 호스트 (검증 수준 다양) |
| 브랜드 감도 | 높음 (에디토리얼·라이프스타일) | 높음 (호텔 라운지, 와인바) | 중상 | 상품 목록 중심 |
| 공급 확보 | 심사 + 크리에이터 영입 + 참가자 육성 | 자체 운영 | 모더레이터 모집 | 공개 등록 |
| 상태 | **출시 전** | 운영 중 | 운영 중 (가입 3만 명, 유료 7,300명 — 회사 자체 발표) | 운영 중 |

> 확인 출처: 필립앤소피 공식 사이트, 세븐픽쳐스(동행클럽) 팀 페이지·채용 공고. 원데이 클래스 플랫폼은 일반적인 성격만 적었다 (세부 수치 확인 필요).

### 5-3. 우리의 차별점 (현재 구현 기준)
1. **호스트 경력 심사**: 경력(필수), 자격·수상, 포트폴리오(https), 가르친 경험 → 공개 프로필에 표시
2. **배움의 명확성**: 모든 클래스에 난이도 + "수업이 끝나면 할 수 있는 것" 필수
3. **소수 정예**: 4~10명 기준
4. **브랜드 감도**: 일반 예약 사이트와 다른 에디토리얼 디자인, 전시장형 갤러리
5. **휴대폰 중심**: 넘기는 갤러리·목록, 하단 고정 신청 버튼
6. **신뢰 장치**: 샘플 표시, 상세 주소는 참가 확정 후 공개, 테스트 결제·환불 흐름 검증, 관리자 2단계 인증·감사 기록

## 9. 검증해야 할 가설과 지표
| 가설 | 지표 | 측정 가능 여부 (현재 시스템) |
|---|---|---|
| 사람들은 "검증된 전문가"에게 돈을 더 낸다 | 상세 페이지 → 신청 전환율, 가격대별 전환 | 신청 수 ✅ / 방문 수 ❌ (분석 도구 필요) |

| 크리에이터 팬덤이 모집을 줄여 준다 | 크리에이터 채널 유입 비율 | ❌ 유입 경로 기록 필요 |
| 호스트가 계속 연다 | 호스트당 월 개설 횟수, 재개설 의사 | 개설 ✅ |
| 참가자가 호스트로 성장한다 | 참가자 → 호스트 신청 전환 | 신청 ✅ / 활동 기록 ❌ |

4. **(계약·법률)** 토스페이먼츠 계약, 약관·환불 규정, 통신판매중개 신고 → 실결제 전환
5. **(운영)** 파일럿 클래스 운영 → 9장 지표 측정
6. **(기획)** 유료 기획 서비스 상품·약관 설계 → 법률 검토 → 개발
