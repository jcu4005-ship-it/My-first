# 드롭 × 모닥불 원 — 구현 계획 (대표 승인 2026-11-20, 구현 전)

> 승인된 시안: 휴대폰 12화면 "드롭 × 모닥불 원" (정해진 시각에 불이 켜지는 원).
> 이 문서는 계획이다. 각 단계는 로컬 전체 검사 → 스테이징 배포(대표 GitHub 승인) 순서로 진행한다.
> 기존 기능은 삭제하지 않는다. DB는 "추가만" 하는 마이그레이션으로 바꾼다.

## 0. 한 문장
정해진 시각(열림 시각)에 원이 열리고, 앉는 사람마다 의자에 불이 켜지며, 빈 의자 하나가 "당신 자리"로 빛난다.

## 1. 지금 있는 것 / 새로 필요한 것

| 시안 화면 | 지금 있는 것 (재사용) | 새로 필요한 것 |
|---|---|---|
| ① 홈 | 팔로우, 다가오는 일정, 남은 자리 | 새 홈 화면, "팔로우한 사람의 다음 원" 고르기, 카운트다운 |
| ② 이번 주 열리는 원 | 일정 목록 | 새 화면 `/drops`, 날짜별 개수, 시각별 묶음 |
| ③ 지금 열린 원 | `/meetups` 목록·검색·필터 | 화면 새 디자인, "곧 닫히는 순" 정렬 |
| ④⑤ 크리에이터 목록·상세 | `/hosts`, 팔로우 | 화면 새 디자인(3열), 다음 원 시각 표시 |
| ⑥⑦ 상세 (열리기 전 / 열림) | 상세, 로고 의자(ChairRing), 남은 자리 | **열림 시각**, 열리기 전 신청 막기, 카운트다운, 남은 자리 자동 새로고침 |
| ⑧ 앉기·결제 | 10분 자리 맡기(`hold_expires_at`), 테스트 결제, 쿠폰 | 화면 새 디자인(밝은 종이 시트) |
| ⑨ 입장권 | 공유 카드 기술(next/og) | 입장권 이미지(스토리 크기, 주소·다른 참가자 정보 없음), 원 완성 화면 |
| ⑩ 내 자리 | 내 예약, 주소, 공지, 캘린더, 길찾기, 대기 | 화면 새 디자인, "알림 건 원" |
| ⑪ 가득 찬 원·대기 | 대기 신청, 자리 나면 알림 | 화면 새 디자인 |
| ⑫ 알림 | 알림함 | **열림 알림**, **1시간 전 알림**, 화면 새 디자인 |
| 아래 탭 | 홈·크리에이터·프로그램·저장·마이 (5개) | 드롭·둘러보기·내 자리·마이 (4개). 저장은 마이 안으로 |

## 2. DB 변경 (추가만)

| 변경 | 내용 | 기존 영향 |
|---|---|---|
| `meetup_sessions.opens_at` (빈 값 허용) | 원이 열리는 시각. **비어 있으면 지금처럼 바로 신청 가능** | 없음 (기존 일정은 모두 비어 있음) |
| `book_session` 수정 | `opens_at`이 미래면 "아직 열리지 않았어요"로 거절 | 신청 함수 변경 → pgTAP·E2E로 검증 |
| `session_open_alerts` (함수로만 쓰기) | "열리면 알림 받기" 신청 기록 | 없음 |
| `meetup_sessions.open_notified_at`, `open_reminded_at` | 알림 중복 방지 | 없음 |
| `private.send_open_alerts` + pg_cron 매분 | 열림 1시간 전·열린 순간에 팔로워 + 알림 신청자에게 알림 | 새 예약 작업 1개 |
| 호스트 일정 폼 | "열림 시각 (선택)" 칸 | 기존 입력 그대로 |

- 남은 자리 숫자는 지금처럼 실제 예약 수(`reserved_count`)만 사용. 가짜 숫자·가짜 카운트다운 금지.
- "실시간"은 처음엔 상세 화면에서 열림 직후 10초마다 다시 불러오는 방식(안전). 실시간 연결(Realtime)은 나중.
- 대기자 30분 우선권은 지금 없음 → 화면 문구는 "자리 나면 알려 드려요"로 사실대로. 우선권은 별도 승인 후.

## 3. 디자인 기반

> 2026-11-20 대표 결정: 검정·주황 대신 색 D안 "미드나잇 네이비 & 골드"로 확정. 신뢰감(크리에이터 소개·경력·활동 기록·후기, 결제 전 정보, 환불 기준), 가독성(글씨 키움·고대비), 홈(서비스 목적·원 작게), 카드(크리에이터·날짜·장소·가격·신청 현황) 개선. 아래 주황 관련 문장은 이전 기록.


- 색: 해 질 녘 갈색(바탕) · 불빛 주황(당신 자리, 주요 버튼) · 살구빛(먼저 앉은 사람) · 어두운 갈색(빈 자리) · 밝은 종이색(정보·결제 시트).
- 의자 원(ChairRing) 새 규칙: 살구빛 = 먼저 앉은 사람, 빛나는 주황 = 당신 자리, 어두운 갈색 = 빈 자리·열리기 전. 가운데 크리에이터 얼굴. 점 무리·사람 모양 금지 유지.
- 글자 대비 4.5:1 이상 검사, "움직임 줄이기" 설정이면 빛 깜빡임 끔.
- PRODUCT.md의 자리 색 규칙을 새 규칙으로 갱신.
