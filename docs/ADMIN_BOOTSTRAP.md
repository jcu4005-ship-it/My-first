# 최초 관리자 지정 절차

> 일반 회원가입과 완전히 분리된 절차입니다. 앱 화면·외부 API로는 실행할 수 없고, **Supabase 프로젝트 소유자 권한**(대시보드 SQL 편집기)으로만 실행됩니다.

## 안전장치

| 장치 | 내용 |
|---|---|
| 실행 위치 | `private` 스키마 함수 — 외부 API에 노출되지 않음 |
| 실행 권한 | 비로그인·로그인 회원·서비스 키(service_role) 모두 실행 권한 없음 (pgTAP 테스트로 확인) |
| 1회성 | 관리자가 1명이라도 있으면 거부. 이후 관리자는 관리자 화면(2단계 인증)에서만 지정 |
| 대상 조건 | 이메일 인증을 마친 회원만 |
| 기록 | `audit_logs`에 `actor_kind = bootstrap`으로 기록 (수정·삭제 불가) |

## 순서 (스테이징 기준, 운영도 동일)

1. 관리자로 쓸 이메일로 **스테이징 사이트에서 일반 회원가입** → 인증 메일의 링크 클릭
2. supabase.com → 스테이징 프로젝트 → **SQL Editor** → 아래 실행 (이메일만 바꿔서)
   ```sql
   select private.bootstrap_first_admin('관리자이메일@example.com', '최초 관리자 지정');
   ```
3. 결과로 회원 ID(UUID)가 나오면 성공. "이미 관리자가 있습니다" 오류면 이미 지정된 상태입니다.
4. 사이트에 다시 로그인 → `/admin` 접속 → 2단계 인증(인증 앱 QR 등록) 완료 → 관리자 화면 사용

## 주의

- 관리자 계정 비밀번호와 인증 앱은 본인만 보관합니다. 인증 앱을 잃어버리면 SQL로 복구 절차가 필요합니다(별도 안내).
- 추가 관리자는 관리자 화면 → 회원 → "관리자 부여"(사유 입력)로 지정하며, 모두 감사 기록에 남습니다.
- 자기 자신의 관리자 권한 회수, 마지막 관리자 회수는 DB가 거부합니다.
