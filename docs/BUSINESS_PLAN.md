## 1. 비전과 가치관 [결정]
**한 문장:** 모두를 위한 곳이 아니다. 우리를 알아보는 사람에게, 스스로를 더 사랑하게 되는 경험을 판다.

- 사람들의 감정과 비위를 맞추지 않는다. 영향을 받는 플랫폼이 아니라 **영향을 주는 플랫폼**.
- **규모의 경제로 경쟁하지 않는다.** 플랫폼을 열렬히 사랑하는 **팬에 집중하는 팬덤 사업**.
- 우리의 색깔에 온전히 집중한다. 개인적인 것이 가장 창의적이다.
- **가격은 대중적인 기준, 가치는 주관적 효용.**
- 조회수·구독자가 아니라 **본질적이고 의미 있는 사람과 데이터**.
- 좋은 커뮤니티의 목적은 **구성원이 스스로를 사랑하게 하는 것**.

**원칙의 구분 [제안]**
| 타협하지 않는 것 (색깔) | 철저히 지키는 것 (신뢰) |
|---|---|
| 어떤 클래스를 열지, 누구를 호스트로 들일지, 멤버십 자격 | 환불·약속한 수업 내용·안전 |
| 톤·디자인·문구 | 개인정보, 결제·정산 정확성, 차별 없는 응대 |

## 2. 무엇을 파는가 (포지셔닝)
- **[결정]** 검증된 전문가·크리에이터가 **4~10명 소수 정예**로 직접 가르치는 오프라인 클래스.
- 핵심 가치: 배우고 결과물을 가져가는 경험 → "나는 이걸 할 수 있는 사람이 됐다" → 스스로를 사랑하게 됨.
- 겉모습: 세련된 어반 라이프스타일 브랜드 (에디토리얼 디자인, 휴대폰 중심).

**경쟁 구도**
| | 파는 것 | 결제 |
|---|---|---|
| 필립앤소피, 동행클럽 | 타인과의 관계 | 멤버십 |
| 프립·탈잉·솜씨당 등 | 경험·취미 | 1회 |
| **Gathering** | **나 자신과의 관계 (배움·성장)** | 1회 + 멤버십 |

- **[제안]** 메시지 1순위는 "배움·성장", 커뮤니티는 "수업 뒤에 이어지는 것". 최근 카피("취향이 맞는 사람들", "A community")는 관계형 플랫폼과 겹치므로 조정 검토.

## 3. 비즈니스 모델: 항공사 방식 [결정: 항공사 모델 / 가져올 범위는 제안]
| 항공사 | Gathering |
|---|---|
| 기본 운임은 누구나 | 공개 클래스는 대중적인 가격 |
| 우선 탑승·라운지 | 멤버 **48시간 우선 예약**, **멤버 우선 좌석** |
| 마일리지 등급 (탄 만큼) | **참석한 만큼** 오르는 등급: Member → Regular → Inner Circle |
| 부가 서비스 | 재료 키트, 애프터 세션, 결과물 촬영 |
| 항공 동맹 | 공간·브랜드 파트너 |
| 라운지 | 장기적으로 오프라인 거점 |

- **가져오지 않는 것:** 많이 태워야 남는 규모 경쟁, 싼 표 경쟁.

## 4. 회원 구조: 일반 회원 vs 멤버십 [결정: 차별화 / 세부는 가설]
| | 일반 회원 | 멤버십 회원 |
|---|---|---|
| 가입 | 누구나 무료 | **클래스 1회 이상 실제 참석자만** 신청 가능 (유료) |
| 예약 | 일반 오픈부터 | 48시간 먼저 |
| 좌석 | 남은 자리 | 멤버 우선 좌석 (예: 8석 중 2석) |
| 전용 경험 | ✕ | Gathering Originals, Members' Table (분기 모임) |
| 초대 | ✕ | 초대권 (팬이 팬을 데려옴) |
| 등급 | — | 참석 기반 승급, Inner Circle은 클래스 기획·호스트 육성 과정으로 연결 |

- 혜택의 중심은 할인이 아니라 **먼저·가까이·깊게**.
- **[가설]** 연간 멤버십 9만~15만 원대, 첫 100명은 **Founding Member** 한정가 + 평생 표시.
- 순서: 공개 클래스로 참석자 확보 → 그중 Founding Member 모집 (클래스가 부족한데 멤버십부터 팔지 않는다).

## 5. 브랜드와 마케팅
### 5-1. 얼굴 대신 브랜드 [결정]
- 창업자 얼굴 노출은 **규모가 커진 뒤**. 초기에는 플랫폼으로 승부.
- 큐레이션·레터·Originals는 **"Gathering 에디터"** 명의 (브랜드 목소리).
- 창업자는 뒤에서: 호스트 섭외, 큐레이션 결정.

### 5-2. 마케팅 엔진 4개
| 엔진 | 역할 |
|---|---|
| ① 호스트 | 자기 팔로워에게 알림 — 초기에 가장 빠른 모집 |
| ② 참가자·멤버 | 결과물 공유, 초대권 |
| ③ 경험 자체 | 공간·키트·결과물 카드 (찍고 싶은 마감) |
| ④ 브랜드 목소리 | 에디터 큐레이션, 월간 레터 (답장·저장·참석으로 평가) |

### 5-3. 호스트의 홍보가 Gathering 팬으로 쌓이게 [결정: 락인 방향 / 장치는 제안]
- **후기·참가 이력·결과물은 Gathering에만 쌓인다** → 가치 기반 락인.
- 신청은 반드시 Gathering 페이지로 → 고객 관계는 플랫폼에.
- 호스트 전용 추천 링크, 공동 브랜딩 홍보 키트, 인증 배지.
- Gathering에서만 되는 것(멤버 우선권·등급·다음 클래스 추천)으로 호스트의 팬이 다른 클래스로 이어지게.
- 수익 배분을 받는 호스트의 홍보물은 "광고/유료 협찬" 표시 (추천·보증 심사지침).
- 원칙: 금지와 제재보다 **"여기 있는 게 더 이득"인 잠금**.

## 6. 호스트 정책
### 6-1. 호스트 유형
| 유형 | 누구 | 화면 표시 [제안] |
|---|---|---|
| Expert | 경력 심사를 통과한 현업 전문가 | Expert 배지 |
| Creator | 콘텐츠 크리에이터 (게스트, 주인공은 Gathering) | Creator 배지 |
| Community Host | 참가자에서 성장한 호스트 | Community Host 배지 |

### 6-2. 호스트 수익 모델: 입장료 없이 수수료 [제안, 창업자 최종 결정 필요]
| 비교 | 수수료 | 평생 1회 입장료 |
|---|---|---|
| 우리가 버는 때 | 호스트가 잘 팔 때 | 들어올 때 한 번 |
| 우리가 노력하는 방향 | 클래스를 잘 팔리게 | 호스트를 많이 모으기 (소수 정예와 반대) |
| 수익 | 계속 증가 | 호스트 수에서 멈춤 |
| 신뢰 | 같이 벌고 같이 잃음 | "돈 냈는데 안 팔린다" 불만, "돈 내면 강사" 인식 |
| 새는 손님 | 생길 수 있음 | 거의 없음 |

**추천 구조:**
> 입장 무료(심사·미션으로 거름) + 판매 수수료 + 추천 링크·단골 재수강은 수수료 인하 + 원하는 호스트만 유료 기획 패키지 + (호스트가 많아지면) Host Pro 월 구독

- **[가설] 수수료:** 기본 등급 30/25/20/15% (신규→핵심 파트너), 크리에이터 섭외·운영 지원 25~30%, 호스트 자체 모집 15~20%, 단골 재수강 추가 인하
- 수수료는 결제 시점 값을 저장 → 과거 거래는 바뀌지 않음.
- 카드 수수료 초기 플랫폼 부담, 쿠폰 부담 주체 구분, 정산은 종료 7일 후 월 2회 **수동 확인**부터.

### 6-3. 호스트 성장 사다리 [결정: 방향]
1단계 (초기): 참가 → 후기 → 활동 → 강점 발견 → 호스트 미션 → 신청·심사 → 개설
- **[제안]** 미션은 활동량보다 **가르칠 능력** 중심 (기획서 1장, 5분 시범 영상, 보조 참여)
- Inner Circle 멤버 → 호스트 육성 과정 우선 초대

2단계 (인지도 확보 후): **유료 클래스 기획 서비스** — 강점 분석, 콘셉트, 커리큘럼, 가격·정원, 상세 페이지, 사진·홍보, 출시 지원
- **[결정] 돈을 냈다고 호스트 자격을 주지 않는다** (심사와 분리)
- 계약에 승인·수익 비보장 명시, 수익 보장 광고 금지, 단계별 환불, 결과물 목록

## 7. 수익 구조 요약
| 수익원 | 시기 |
|---|---|
| ① 클래스 거래 수수료 | 출시부터 (실결제 전환 후) |
| ② 멤버십 (연간) | 공개 클래스 운영·참석자 확보 후 |
| ③ 부가 경험 (키트, 애프터 세션, 촬영) | 파일럿부터 소규모 |
| ④ 유료 클래스 기획 패키지·콘텐츠 제작 | 인지도 확보 후 |
| ⑤ Host Pro 구독 | 호스트가 많아진 뒤 |

**단위 경제 예시 [가설]:** 5만 원 × 8명 = 40만 원 → 수수료 20% 8만 원 − 카드 수수료(약 3% 가정) ≈ **1회 약 6.8만 원** (마케팅·인건비 전)
→ 팬덤 사업이므로 **멤버 1인당 연간 참석·지출**과 **호스트당 개설 횟수**가 생존 지표. 대신 마케팅 비용은 낮아야 한다.

## 10. 실행 로드맵
| 단계 | 할 일 | 성격 |
|---|---|---|
| 0 | 서비스명·브랜드 목소리(에디터 톤) 확정, 사진 확보 | 브랜드 |
| 1 | 파일럿 호스트 5명 섭외 (Expert·Creator 혼합, 팔로워 적어도 실력 있는 사람 포함) | 운영 |
| 2 | 토스 계약·약관·환불 규정·통신판매중개 신고 → 실결제 전환 | 계약·법률 |
| 3 | 공개 클래스 운영 → 참석률·만족도·재방문 측정 | 검증 |
| 4 | 참석자 중 Founding Member 100명, 첫 Originals·Members' Table | 팬덤 |
| 5 | 개발: 출석 체크 → 후기 → 호스트 추천 링크·유입 기록 → 멤버십(결제·등급·우선 예약·멤버 좌석·초대권) → 호스트 유형 배지 | 제품 |
| 6 | 호스트 성장 사다리 1단계 운영, 첫 Community Host 배출 | 공급 |
| 7 | 유료 기획 서비스 상품·약관 → 법률 검토 → 출시 | 수익 다각화 |

**현재 상태:** 제품 핵심 기능(가입·호스트 심사·클래스·신청·테스트 결제·환불·관리자)은 스테이징에서 자동 검증 완료. **실제 회원·호스트·매출은 0, 출시 전.** 실결제·후기·출석·멤버십·사진은 미구현.

## 11. 창업자가 정해야 할 것
1. 호스트 수익 모델 최종 선택 (추천: 입장료 없이 수수료)
2. 서비스 이름
3. 브랜드 목소리 (에디터 톤, 대표 문장)
4. 멤버십 가격·혜택 첫 버전
5. 파일럿 호스트 5명 후보
6. 메인 카피를 "배움·성장" 중심으로 조정할지
