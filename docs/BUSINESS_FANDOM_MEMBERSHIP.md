# Gathering 팬덤 사업 구조: 멤버십 × 창업자 큐레이터 (2026-11-06, 초안)

> 창업자 가치관에서 출발한 사업 구조 초안. 가격·혜택 숫자는 모두 **가설**이며 파일럿으로 검증한다.
> 개발은 보류 중이다. 이 문서는 사업 결정용이다.

## 0. 출발점 (창업자 가치관)
- 모두의 사랑을 받으려 하지 않는다. 나와 플랫폼을 열렬히 사랑하는 팬에게 집중한다.
- 영향을 받는 플랫폼이 아니라 영향을 주는 플랫폼.
- 규모의 경제로 경쟁하지 않는다.
- 가격은 대중적인 기준, 가치는 주관적 효용.
- 조회수·구독자 대신 본질적이고 의미 있는 사람과 데이터.
- 개인적인 것이 가장 창의적이다.
- 좋은 커뮤니티의 목적은 구성원이 스스로를 사랑하게 하는 것.

**한 문장:** 모두를 위한 곳이 아니다. 나를 알아보는 사람에게, 스스로를 더 사랑하게 되는 경험을 판다.

## 1. 항공사 모델에서 가져오는 것 / 가져오지 않는 것
| 가져온다 | 가져오지 않는다 |
|---|---|
| 같은 비행기, 다른 경험 (좌석 구분) | 많이 태워야 남는 규모 경쟁 |
| 우선 탑승·라운지 같은 **멤버 우선권** | 싼 표로 좌석 채우기 경쟁 |
| 탄 만큼 쌓이는 **충성 등급** | |
| 부가 서비스 (좌석 지정, 기내식 ↔ 재료 키트, 애프터 세션) | |
| 동맹 (공간·브랜드 파트너) | |

## 2. 회원 구조: 일반 회원 vs 멤버십 회원
### 2-1. 원칙
1. **일반 회원도 환영한다.** 공개 클래스는 누구나 대중적인 가격에 신청할 수 있다. 첫 경험의 문은 낮게.
2. **멤버십은 "아무나"가 아니다.** 클래스를 **1회 이상 실제로 참석한 사람**만 가입할 수 있다. (돈만으로 들어오지 않는다 → 팬만 남는다)
3. **혜택의 중심은 할인이 아니라 "먼저, 가까이, 깊게"다.** 할인 경쟁은 규모 사업의 방식이다.

### 2-2. 비교표
| | 일반 회원 | 멤버십 회원 |
|---|---|---|
| 가입 | 누구나 무료 | 클래스 1회 이상 참석 후 신청 (유료) |
| 공개 클래스 신청 | 일반 오픈 시점부터 | **48시간 먼저** (우선 탑승) |
| 좌석 | 남은 좌석 | 클래스마다 **멤버 우선 좌석** 일부 확보 (예: 8석 중 2석) |
| 가격 | 정가 | 멤버가 (예: 10%) — 부담은 플랫폼 |
| 멤버 전용 클래스 | ✕ | ✓ **Gathering Originals**, 창업자 기획 클래스 |
| 창업자와의 시간 | ✕ | ✓ **Founder's Table** (분기별 소규모 모임) |
| 대기 신청 | 일반 순서 | 우선 순서 |
| 지인 초대 | ✕ | ✓ 연 n회 초대권 (팬이 팬을 데려옴) |
| 부가 경험 | 개별 구매 | 일부 포함 또는 우선 구매 (재료 키트, 애프터 세션, 결과물 촬영) |
| 등급 | — | 참석할수록 상승: **Member → Regular → Inner Circle** |

### 2-3. 등급 (마일리지 방식, 돈이 아니라 참석으로)
| 등급 | 조건 (예시) | 추가 혜택 |
|---|---|---|
| Member | 멤버십 가입 | 위 기본 혜택 |
| Regular | 1년 6회 참석 | 우선 예약 72시간, 초대권 추가 |
| Inner Circle | 1년 12회 참석 + 후기·추천 활동 | 신규 클래스 기획 참여, 호스트 육성 과정 우선 초대 (호스트 성장 사다리와 연결) |

### 2-4. 가격 (가설)
- 원칙: **대중적인 기준.** 한 번에 크게 받지 않고, 몇 번 오면 본전이 되는 수준.
- 후보: 연간 멤버십 (예: 9만~15만 원대) / 처음 100명은 **Founding Member** 한정가 + 평생 표시
- 본전 계산 예: 5만 원 클래스 10% 할인 × 연 6회 = 3만 원 절약 + 우선권·전용 클래스·창업자 모임 → **가치는 할인이 아니라 접근권에서 온다**
- 비교: 동행클럽 3개월 약 15만 원 (회사 발표), 필립앤소피 가격은 공개 자료로 확인하지 못함

## 3. 창업자 얼굴 노출: "큐레이터" 역할
팬덤의 대상은 결국 **사람과 관점**이다. 창업자는 운영자가 아니라 **큐레이터**로 보인다.
| 장치 | 내용 |
|---|---|
| Curator's Pick | 사이트에 창업자가 고른 클래스와 고른 이유 (짧은 글, 얼굴 사진) |
| Founder's Letter | 월 1회 편지: 이번 달 클래스, 만난 사람, 생각. 조회수가 아니라 답장 수를 본다 |
| Gathering Originals | 창업자가 직접 기획·섭외한 클래스. 현장에 창업자가 있다 |
| Founder's Table | 멤버 전용 분기 모임 (8~10명) |
| 첫 클래스 인사 | 파일럿 기간에는 모든 첫 클래스에 창업자가 짧게 인사 |

주의:
- 개인정보·사생활 경계 미리 정하기 (공개하는 것과 하지 않는 것)
- 창업자 1인에게 모든 것이 걸리지 않도록, 6~12개월 뒤 "큐레이터 팀" (Inner Circle 출신) 구성
- 크리에이터 강사는 **게스트**, 주인공은 Gathering의 관점

## 4. "비위를 맞추지 않는다"와 "약속을 지킨다"의 구분
| 타협하지 않는 것 (색깔) | 철저히 지키는 것 (신뢰) |
|---|---|
| 어떤 클래스를 열지, 누구를 호스트로 들일지 | 환불 규정, 수업 약속 내용, 안전 |
| 사이트 톤·디자인·문구 | 개인정보, 결제·정산 정확성 |
| 멤버십 자격 기준 | 차별 없는 응대 (취향으로 고르되 사람을 무시하지 않는다) |

## 5. 의미 있는 데이터 (조회수 대신)
| 지표 | 왜 |
|---|---|
| "Gathering이 없어지면 아주 아쉽다" 응답 비율 (목표 40% 이상) | 진짜 팬이 있는지 |
| 연 3회 이상 참석자 수 | 팬의 수 |
| 멤버 1인당 연간 참석·지출 | 팬덤 사업의 생존 지표 |
| 초대·추천으로 온 비율 | 팬이 팬을 데려오는지 |
| 참석률 | 약속의 무게 |
| "수업 전후 나에 대한 느낌이 달라졌다" 응답 | 커뮤니티 목적 그 자체 |
| 참가자 → 호스트 성장 수 | 영향을 받던 사람이 영향을 주는 사람이 되는지 |
| 멤버십 갱신률 | 사랑이 1년을 버티는지 |

## 6. 리스크
1. **멤버십은 클래스가 충분해야 가치가 있다.** 클래스가 적은데 멤버십부터 팔면 "낸 돈에 비해 쓸 게 없다"가 된다. → 공급(파일럿 호스트) 확보 후, Founding Member로 소수부터.
2. **구독 결제 법규**: 자동 갱신 사전 고지, 쉬운 해지, 중도 해지 환불 기준 (전자상거래 관련 규정 검토 필요).
3. **멤버 할인 비용**: 플랫폼이 부담하면 수수료 수익이 줄어든다. → 할인보다 우선권·전용 경험 중심으로.
4. **창업자 의존·소진**: 큐레이터 팀으로 점차 분산.
5. **폐쇄성**: 팬만 남기면 새로운 사람이 들어오기 어렵다. → 공개 클래스와 초대권으로 입구는 항상 열어 둔다.

## 7. 시작 순서 (제안)
1. 서비스명·창업자 프로필(사진·짧은 소개) 확정
2. 파일럿 호스트 5명으로 공개 클래스 운영 (일반 회원 대상)
3. 참석자 중에서 **Founding Member 100명** 모집 (참석자만 자격)
4. 첫 Gathering Originals + Founder's Table 1회
5. 5장 지표 측정 → 가격·혜택 조정
6. 이후 개발: 멤버십 결제·등급·우선 예약·멤버 좌석·초대권 (승인 후)
