# 일반 공개 전 필수 항목 (Launch Blockers)

> 아래 항목이 모두 완료되기 전에는 일반 공개(운영 오픈)하지 않습니다. 단계별 보고서에서 상태를 갱신합니다.

| # | 항목 | 상태 | 관련 | 완료 조건 |
|---|---|---|---|---|
| L1 | **회원 탈퇴 기능** | ✅ 구현 (비밀번호 재확인, 익명화, 로그인 차단, 예정 신청 취소·환불). 스테이징 실환경 미검증 | 설계안 6-1, 9-4 D4 | 탈퇴 신청 → 계정 비활성·로그인 차단 → 보존 대상 외 개인정보 파기·익명화 → 감사 기록. 부정 테스트 포함 |
| L2 | **개인정보 보유·파기 기준** | ⏳ 법률 검토 필요 | 설계안 9-4 D4, 9-2 E5 | 항목별 보유 기간(전자상거래법 거래기록 등)과 파기 방법 확정 → 문서화 → 탈퇴·정기 파기 로직에 반영 |
| L3 | 약관·개인정보처리방침·동의 문구 법률 검토 | ⏳ 임시 문안 사용 중 (`draft-2026-11-03`) | 설계안 9-4 D1 | 확정 문안 반영, 문서 버전 갱신 |
| L4 | 만 14세 미만 가입 차단 방식 검토 | ⏳ 자기 확인 체크박스 방식 | 설계안 9-4 | 법률 검토 결과에 따라 유지 또는 보강 |
| L5 | 자체 메일 발송(SMTP) 연결 | ⏳ | STAGING_SETUP A-8 | 운영 프로젝트에 발송 도메인 인증된 SMTP 연결, 인증·재설정 메일 수신 확인 |
| L6 | 관리자 인증 앱 분실 시 복구 절차 | ⏳ | ADMIN_BOOTSTRAP | 문서화 + 감사 기록 남는 복구 방법 |
| L7 | 운영 Supabase 프로젝트 분리 생성·설정 | ⏳ | STAGING_SETUP | 스테이징과 다른 프로젝트·키·DB, Auth 설정 확인 스크립트 통과 |
| L8 | 설계안 9장 출시 전 검토 항목 (PG·통신판매중개·주류·세무) | ⏳ | 설계안 9장 | 9-7 일정표의 "출시 전 필수" 항목 완료 |
