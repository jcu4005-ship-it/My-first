# 운영자 카카오톡 알림 설정 (새 호스트 지원서가 오면 대표 카톡으로)

> 코드는 이미 들어 있고, **아래 값이 없으면 알림을 보내지 않습니다.** 값을 넣어야 켜집니다.
> 보내는 내용: "[서비스명] 새 호스트 지원서가 도착했어요" + 관리자 화면 링크. **지원자 이름·연락처·답변은 보내지 않습니다.**

## 준비 (대표가 카카오 쪽에서 한 번만)
1. https://developers.kakao.com 에 카카오 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가** (이름 예: 운영 알림)
2. 앱 설정 → **앱 키**에서 **REST API 키**를 확인합니다. (비밀로 취급)
3. **제품 설정 → 카카오 로그인**을 **활성화**하고, **Redirect URI**에 `https://localhost:3000/oauth` 를 등록합니다. (인증 코드를 받을 임시 주소)
4. **동의항목**에서 **카카오톡 메시지 전송(talk_message)** 을 "선택 동의"로 설정합니다.
5. **플랫폼 → Web**에 사이트 주소(스테이징·운영)를 등록합니다. (알림의 "확인하기" 링크가 열리려면 필요)
6. (보안) **카카오 로그인 → 보안 → Client Secret**을 만들었다면 그 값도 함께 사용합니다.

## 리프레시 토큰 받기 (대표 본인 계정으로 한 번 동의)
1. 브라우저 주소창에 아래 주소를 입력합니다. (`REST_API_KEY` 자리에 위 키)
   `https://kauth.kakao.com/oauth/authorize?client_id=REST_API_KEY&redirect_uri=https://localhost:3000/oauth&response_type=code&scope=talk_message`
2. 로그인하고 **동의**하면 주소창이 `https://localhost:3000/oauth?code=...` 로 바뀌며 오류 화면이 나옵니다. 정상입니다. `code=` 뒤의 값을 복사합니다. (5분 안에 사용)
3. 이 값을 개발 도우미(저)에게 직접 붙이지 말고, 아래 "토큰 교환"은 **터미널에서 대표가 직접** 하거나, 도우미가 안내하는 방법으로 진행합니다. 토큰은 비밀번호와 같습니다.
4. 교환 결과의 `refresh_token` 값을 아래 환경변수에 넣습니다.

## 넣을 환경변수 (Vercel Preview/Production → Settings → Environment Variables)
| 이름 | 값 |
|---|---|
| `KAKAO_REST_API_KEY` | 카카오 REST API 키 |
| `KAKAO_REFRESH_TOKEN` | 위에서 받은 refresh_token |
| `KAKAO_CLIENT_SECRET` | (Client Secret을 켠 경우에만) |

## 알아둘 한계
- **리프레시 토큰은 60일 유효**합니다. 만료 1개월 전부터는 사용 시 새 토큰이 발급되지만, 이 코드는 새 토큰을 저장하지 못합니다. **60일 넘게 알림이 한 번도 안 가면 토큰을 다시 받아야** 합니다. 카톡이 갑자기 안 오면 가장 먼저 의심하세요.
- **"나에게 보내기"는 대표 본인에게만** 갑니다. 직원 여러 명에게 보내려면 알림톡이 필요합니다.
- **알림톡(정식 방식)**: 사업자등록증·카카오 비즈채널·메시지 대행사 가입과 템플릿 심사가 필요하고 건당 비용이 있습니다. 사업자등록증이 나온 뒤 전환을 권장합니다.
- 알림이 실패해도 **지원서 제출은 그대로 성공**합니다. 실패는 서버 기록에 사유만 남습니다.
