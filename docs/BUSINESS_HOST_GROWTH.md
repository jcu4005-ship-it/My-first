# 호스트 육성 및 유료 클래스 기획 사업모델 (2026-11-05, 창업자 제안 + 검토 의견)

> 상태: **기획 단계.** 아래 기능은 아직 만들지 않았다. 개발은 단계별로 창업자 승인 후 진행한다.

## 1. 창업자 제안 요약

### 1단계 — 커뮤니티 기반 호스트 육성 (초기)
참가자가 클래스를 경험하고 활동 미션을 수행하며 호스트로 성장한다.
클래스 참여 → 후기 작성 → 커뮤니티 활동 → 관심사·강점 발견 → 호스트 미션 → 호스트 신청·심사 → 클래스 개설.
진입 비용을 최소화하고, 실제 활동으로 양질의 호스트를 발굴한다.

### 2단계 — 유료 호스트 기획 서비스 (회원·브랜드 인지도 확보 후)
경험·관심사·아이디어를 판매 가능한 오프라인 클래스로 만드는 전문 서비스.
강점·경험 분석 / 주제·콘셉트 기획 / 커리큘럼·진행 방식 / 가격·정원 / 상세 페이지 / 사진·홍보 콘텐츠 / 초기 모집·출시 지원.

### 수익 구조
1. 호스트 기획 패키지 2. 클래스·콘텐츠 제작 3. 클래스 거래 수수료

### 원칙
- **호스트 자격 심사와 유료 기획 서비스는 분리한다. 돈을 냈다는 이유로 호스트 자격을 주지 않는다.**
- 장기 목표: 일반인의 경험과 강점을 상품화하는 "클래스 기획 플랫폼".

## 2. 검토 의견

### 좋은 점
- 공급(호스트) 부족이라는 마켓플레이스의 가장 큰 문제를 **수요(참가자)에서 공급을 길러 내는 구조**로 푼다. 수업을 들어 본 사람이 호스트가 되면 품질 기준을 이미 몸으로 안다.
- 수익원이 거래 수수료 하나에 의존하지 않는다. 기획 서비스는 클래스가 적은 초기에도 매출을 만들 수 있다.
- "자격 심사 ≠ 유료 서비스" 원칙은 신뢰의 핵심이다. 반드시 지킨다.

### 주의할 점
1. **포지셔닝 충돌**: 지금 브랜드 약속은 "검증된 전문가". 1단계의 "일반 참가자 → 호스트"와 부딪힐 수 있다.
   → 해결안: 호스트 등급을 나눠 화면에 표시한다. 예: **Expert**(경력 심사 통과 전문가) / **Community Host**(활동으로 성장한 호스트). 참가자가 무엇을 기대할지 분명해진다.
2. **"돈 내면 강사가 된다"로 오해받을 위험**(2단계): 창업·부업 컨설팅처럼 보이면 불만·분쟁이 생기기 쉽다.
   → 계약서에 "기획 서비스 구매는 호스트 승인·수익을 보장하지 않음"을 명확히, 수익 보장·과장 광고 금지(표시광고법), 단계별 환불 규정, 결과물(커리큘럼 문서, 상세 페이지 초안 등) 목록을 미리 약속.
3. **순서**: 2단계는 "충분한 회원·인지도" 이후가 맞다. 실적(성공한 클래스 사례)이 없으면 기획 서비스의 가치를 증명하기 어렵다. → 1단계에서 나온 성공 사례를 2단계 영업 자료로 쓴다.
4. **미션 설계**: 활동량만 세면 "후기 많이 쓰는 사람"이 호스트가 된다. 미션은 **가르칠 능력**을 보여 주는 것 위주로 (예: 내가 열고 싶은 클래스 기획서 1장, 5분 미니 시범 영상, 다른 호스트 클래스 보조 참여).

## 3. 지금 시스템과의 연결

| 1단계 요소 | 현재 상태 | 필요한 것 |
|---|---|---|
| 클래스 참여 | 있음 (신청·결제·취소) | **출석 기록** (호스트가 참석 체크) — 참여를 "신청"이 아니라 "실제 참석"으로 세기 위해 |
| 후기 작성 | 없음 | 참석한 사람만 쓸 수 있는 후기 (별점 + 글 + 결과물 사진은 나중) |
| 커뮤니티 활동 | 없음 | 초기에는 오프라인·운영팀 기록으로 대체, 기능은 나중 |
| 관심사·강점 발견 | 일부 (회원 관심사 칸 있음) | 마이페이지에 "나의 활동 기록" |
| 호스트 미션 | 없음 | 마이페이지 "호스트 준비도" 체크리스트 (참석 n회, 후기 n개, 기획서 제출) — 대부분 기존 데이터로 계산 |
| 호스트 신청·심사 | 있음 (경력 필수) | 등급 구분(Expert / Community Host), Community Host는 경력 대신 활동 기록·기획서로 심사 |
| 클래스 개설 | 있음 (작성→검수→공개) | 변경 없음 |

2단계(유료 기획 서비스)는 클래스 결제와 다른 "서비스 주문" 구조, 진행 단계 관리, 결과물 전달, 별도 약관·환불 규정이 필요하다. → 1단계 검증 후 설계.

## 4. 추천 진행 순서
1. (운영) 파일럿: 전문가 호스트 5명으로 첫 클래스 운영 — 공급의 질 기준 만들기
2. (개발) 출석 체크 → 참석자 후기 → 마이페이지 활동 기록·호스트 준비도
3. (개발) 호스트 등급(Expert / Community Host) 표시와 등급별 심사 기준
4. (운영) 첫 Community Host 배출 사례 만들기
5. (기획) 유료 기획 서비스 상품·약관·환불 규정 설계 → 법률 검토 → 개발
